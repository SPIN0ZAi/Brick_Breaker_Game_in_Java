# Brick Breaker Game 🎮

A simple **Brick Breaker** game built using Java and Swing! Control the paddle, break the bricks, and score points! 🧱✨

## 🚀 Features
- 🎾 **Classic Brick Breaker Mechanics** – Move the paddle & hit the ball!
- 🔥 **Brick Destruction** – Break bricks to earn points.
- 🎨 **Colorful UI** – Simple but engaging graphics.
- 🎯 **Score Tracking** – Keep track of your high score!

---

## 🎮 How to Play
1. Use **Left ⬅️** and **Right ➡️** arrow keys to move the paddle.
2. Hit the ball with the paddle to break the bricks.
3. Clear all bricks to win! 🎉
4. If the ball falls below the paddle, **Game Over**! 😢

---

## 🛠 How to Run
1. Clone the repository:
   ```sh
   git clone https://github.com/yourusername/brick-bracker.git
   ```
2. Open the project in your favorite Java IDE (e.g., **IntelliJ, Eclipse, VS Code**).
3. Compile and run the `Main.java` file.
